# FPL Live League Points

This is a web application that displays live points for your Fantasy Premier League mini-league in a table format.

The mobile version shows less information than the desktop version.

# Usage

To use a non-default league ID (default: 908457), add `?league=YOUR_LEAGUE_ID` to the URL.

To use a non-default gameweek (default: most recent), add `?gw=YOUR_GAMEWEEK` to the URL.

Combine these together with eg:

```
http://localhost:5000/?league=908457&gw=1
```

If in desktop mode, you can also change gameweek with the arrows.
